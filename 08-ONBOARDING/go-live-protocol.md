# Go-Live Protocol

## Pre-Launch Checklist

### 7 Days Before
- [ ] All deliverables finalised and approved.
- [ ] CRM configured and tested.
- [ ] Email sequences loaded and tested.
- [ ] Proposal templates uploaded.
- [ ] Team training scheduled.
- [ ] Support channel established.

### 3 Days Before
- [ ] Final UAT completed and signed off.
- [ ] Spam scores verified.
- [ ] Deliverability tested.
- [ ] Backup plan documented.
- [ ] Escalation contacts shared.

### 1 Day Before
- [ ] Team training completed.
- [ ] All users have access.
- [ ] Monitoring dashboard live.
- [ ] First sequence scheduled.
- [ ] Launch communication sent.

---

## Launch Day

### Morning
- 08:00 - Final system check.
- 09:00 - Launch announcement to team.
- 10:00 - First outreach sequence goes live.
- 11:00 - First proposal sent using new template.

### Afternoon
- 14:00 - Team check-in (15 mins).
- 15:00 - First reply received / handled.
- 16:00 - End-of-day report sent to client.

---

## Week 1 Hypercare

| Day | Activity |
|-----|----------|
| Day 1 | Launch + monitoring |
| Day 2 | Team check-in + issue resolution |
| Day 3 | First metrics review |
| Day 4 | Process refinement |
| Day 5 | Week 1 report |

---

## Success Criteria

| Metric | Target |
|--------|--------|
| Outreach send success | 100% |
| Email deliverability | > 95% |
| Template usage rate | > 80% |
| Team adoption (survey) | > 7/10 |
| Critical issues | 0 |

---

## Rollback Plan

If critical issues arise:
1. Pause all automated sequences.
2. Revert to previous process.
3. Document issue and root cause.
4. Fix and re-test.
5. Re-launch.

**Rollback trigger**: Any issue affecting > 20% of outreach or proposals.
