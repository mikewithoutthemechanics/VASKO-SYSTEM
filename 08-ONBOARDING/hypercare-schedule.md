# Hypercare Schedule

## Definition
Hypercare is the 14-day period immediately following go-live where VASKO provides enhanced support to ensure smooth adoption.

---

| Day | Time | Activity | Owner |
|-----|------|----------|-------|
| Mon | 08:00-09:00 | Launch readiness check | VASKO |
| Mon | 10:00 | Go-live announcement | Client |
| Mon | 14:00 | First sequence live | VASKO |
| Tue | 09:00 | Daily standup (15 mins) | Both |
| Wed | 09:00 | Daily standup (15 mins) | Both |
| Thu | 09:00 | Daily standup (15 mins) | Both |
| Fri | 09:00 | Daily standup (15 mins) | Both |
