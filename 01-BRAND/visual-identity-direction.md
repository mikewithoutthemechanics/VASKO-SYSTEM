# Visual Identity Direction

## Colour Palette

| Role | Hex | Usage |
|------|-----|-------|
| Primary | `#0f172a` | Backgrounds, headers, dark surfaces |
| Surface | `#1e293b` | Cards, sidebars, elevated panels |
| Accent | `#38bdf8` | CTAs, links, active states, highlights |
| Text Primary | `#f8fafc` | Headings, body text on dark |
| Text Secondary | `#94a3b8` | Supporting text, captions |
| Success | `#4ade80` | Confirmations, positive metrics |
| Warning | `#facc15` | Alerts, pending states |
| Error | `#f87171` | Errors, destructive actions |

## Typography

| Element | Font | Weight | Size |
|---------|------|--------|------|
| Headings | Inter | 700 / 600 | 24px - 48px |
| Body | Inter | 400 / 500 | 16px |
| Code / Data | JetBrains Mono | 400 / 500 | 14px |
| Captions | Inter | 400 | 12px |

## Layout Principles
- **Generous whitespace**: Minimum 24px padding on containers.
- **Grid-based**: 12-column grid on desktop, 4-column on mobile.
- **Visual hierarchy**: Size > weight > colour. Do not rely on colour alone to convey meaning.
- **Card over table**: Prefer card layouts for proposals and dashboards.

## Component Style
- Border radius: 8px (small), 10px (medium), 14px (large).
- Shadows: Subtle, almost flat. Use `0 4px 6px -1px rgba(0,0,0,0.3)`.
- Borders: 1px solid `#334155` on dark, `#e2e8f0` on light.
- Hover states: Background shift to `#334155` (dark) or `#f1f5f9` (light).

## Imagery
- Product screenshots: Dark UI mockups with accent highlights.
- Diagrams: Clean, flat icons. No gradients. Navy + accent colour scheme.
- Photography: Real office environments, authentic faces. Avoid stock smiling.

## Iconography
- Use emoji as primary icons for speed and scalability.
- Keep icon size consistent: 16px (inline), 20px (buttons), 24px (headers).
