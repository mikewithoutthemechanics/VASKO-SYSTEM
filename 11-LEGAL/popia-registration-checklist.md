# POPIA Registration Checklist

## POPIA (Protection of Personal Information Act) Compliance Checklist

## 1. Information Officer

- [ ] Appoint an Information Officer.
- [ ] Register Information Officer with the Information Regulator.
- [ ] Publish Information Officer contact details on website.

---

## 2. Data Mapping

- [ ] Inventory all personal data collected.
- [ ] Document data sources and purposes.
- [ ] Map data flows (collection, storage, sharing, deletion).
- [ ] Identify data categories (client, prospect, employee, supplier).

---

## 3. Lawful Basis for Processing

- [ ] Identify lawful basis for each processing activity.
- [ ] Document consent mechanisms (where applicable).
- [ ] Ensure contracts include data processing clauses.
- [ ] Maintain records of processing activities (ROPA).

---

## 4. Data Subject Rights

- [ ] Process for handling access requests.
- [ ] Process for handling correction requests.
- [ ] Process for handling erasure requests.
- [ ] Process for handling objection requests.
- [ ] Response timeframe: 30 days.

---

## 5. Security Measures

- [ ] Access controls implemented.
- [ ] Encryption in transit and at rest.
- [ ] Regular security assessments.
- [ ] Incident response plan documented.
- [ ] Breach notification procedure (72 hours to regulator).

---

## 6. Third-Party Processors

- [ ] List all third-party processors.
- [ ] Ensure Data Processing Agreements in place.
- [ ] Audit processor compliance annually.

---

## 7. Direct Marketing

- [ ] Opt-in mechanism for marketing communications.
- [ ] Opt-out mechanism in every communication.
- [ ] Do-not-call registry checked before outreach.
- [ ] Record of consent maintained.

---

## 8. Retention and Disposal

- [ ] Data retention policy defined.
- [ ] Retention periods documented per data category.
- [ ] Secure disposal procedure for expired data.

---

## 9. Training and Awareness

- [ ] POPIA training for all staff.
- [ ] Annual refresher training.
- [ ] New hire onboarding includes privacy module.

---

## 10. Monitoring and Review

- [ ] Quarterly privacy audit.
- [ ] Annual privacy impact assessment (PIA) for new systems.
- [ ] Incident register maintained.
