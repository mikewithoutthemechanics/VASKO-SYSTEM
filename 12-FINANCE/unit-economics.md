# Unit Economics

## Definitions

| Metric | Formula | Target |
|--------|---------|--------|
| Customer Acquisition Cost (CAC) | Total sales + marketing spend / new clients | < R15,000 |
| Lifetime Value (LTV) | Average revenue per client × average lifespan | > R150,000 |
| LTV:CAC ratio | LTV / CAC | > 3:1 |
| Gross margin | (Revenue - COGS) / Revenue | > 70% |
| Payback period | CAC / monthly revenue per client | < 3 months |
| Churn rate | Lost clients / total clients | < 5% monthly |
| Net Revenue Retention | (Starting MRR + expansion - churn) / starting MRR | > 110% |

---

## Calculation Example

### Assumptions
- Average monthly fee: R22,500 (Prime)
- Average setup fee: R10,000
- Average client lifespan: 18 months
- Sales and marketing spend: R50,000/month

### CAC Calculation
| Channel | Spend | Clients Acquired | CAC |
|---------|-------|------------------|-----|
| Outreach | R20,000 | 5 | R4,000 |
| LinkedIn | R15,000 | 3 | R5,000 |
| Referrals | R10,000 | 4 | R2,500 |
| Content | R5,000 | 1 | R5,000 |
| **Total** | **R50,000** | **13** | **R3,846** |

### LTV Calculation
| Revenue Stream | Amount | Duration |
|----------------|--------|----------|
| Monthly fees | R22,500 | 18 months = R405,000 |
| Setup fee | R10,000 | One-time |
| Add-ons | R5,000 | Estimated |
| **Total** | **R420,000** | |

### Unit Economics Summary

| Metric | Value | Status |
|--------|-------|--------|
| CAC | R3,846 | ✅ Healthy |
| LTV | R420,000 | ✅ Strong |
| LTV:CAC | 109:1 | ✅ Excellent |
| Gross margin | 75% | ✅ Target met |
| Payback period | 0.2 months | ✅ Excellent |
| NRR | 115% | ✅ Strong |

## Action Items

| Metric | If Below Target | Action |
|--------|-----------------|--------|
| CAC | > R15,000 | Optimise channels, improve conversion |
| LTV | < R150,000 | Increase pricing, reduce churn |
| LTV:CAC | < 3:1 | Reduce CAC or increase LTV |
| Gross margin | < 70% | Reduce COGS, increase pricing |
| Payback | > 3 months | Improve onboarding, reduce setup costs |
