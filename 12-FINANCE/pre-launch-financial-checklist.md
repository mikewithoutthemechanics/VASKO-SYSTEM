# Pre-Launch Financial Checklist

## 6 Months Before Launch

- [ ] Finalise pricing strategy and all tier sheets.
- [ ] Set up business bank account.
- [ ] Register for tax (VAT, income tax).
- [ ] Set up accounting software (Xero / QuickBooks).
- [ ] Create invoice templates.
- [ ] Set up payment processing (PayPal, Stripe, EFT).
- [ ] Draft cash flow projection (12 months).
- [ ] Identify break-even point.

## 3 Months Before Launch

- [ ] Finalise annual budget.
- [ ] Set up expense tracking.
- [ ] Create pricing approval workflow.
- [ ] Define discount authority matrix.
- [ ] Set up CRM financial fields (deal value, stage, close date).
- [ ] Create unit economics model.
- [ ] Identify key financial KPIs.

## 1 Month Before Launch

- [ ] Test invoicing flow end-to-end.
- [ ] Test payment reconciliation.
- [ ] Create financial reporting template.
- [ ] Set up monthly close process.
- [ ] Define payment terms and late payment policy.
- [ ] Create change request billing process.
- [ ] Brief team on financial protocols.

## Launch Day

- [ ] First invoice sent.
- [ ] First payment received and reconciled.
- [ ] CRM updated with first deal.
- [ ] Financial dashboard live.

## Key Financial Metrics to Track

| Metric | Target |
|--------|--------|
| Monthly recurring revenue (MRR) | R[Target] |
| Annual recurring revenue (ARR) | R[Target] |
| Customer acquisition cost (CAC) | < R[X] |
| Lifetime value (LTV) | > R[X] |
| LTV:CAC ratio | > 3:1 |
| Gross margin | > 70% |
| Burn rate | R[X]/month |
| Runway | > 12 months |
